# Steam Koshel

**Твой Steam-профиль в цифрах — и в одном красивом портрете.**

Steam Koshel собирает открытые данные профиля Steam в понятную карточку: сколько стоит библиотека и инвентарь, сколько часов ты реально вложил, что говорит твой бэклог, какие трофеи самые редкие и во что ты играешь на самом деле — а не во что собирался.

Проект работает на одном источнике данных — публичном Steam Web API через собственный Python-бэкенд. Никаких встроенных демо-профилей: на первом экране чистая форма, а всё, что вы видите дальше, посчитано по реальному профилю.

| Что нужно | Что получаешь |
|---|---|
| Python-бэкенд + бесплатный `STEAM_API_KEY` | реальные данные любого открытого профиля Steam |

---

## Быстрый старт

```powershell
cd "C:\Steam Koshel"
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# вставь STEAM_API_KEY в .env
uvicorn app.main:app --reload --port 8000
```

Открой <http://127.0.0.1:8000>. Эту же страницу отдаёт бэкенд, поэтому `fetch('/api/profile')` работает без CORS-танцев.

Ключ берётся бесплатно здесь: <https://steamcommunity.com/dev/apikey> (нужен любой домен, подойдёт `localhost`).

> Из `file://` страница откроется, но данные не загрузятся: браузеру нужен настоящий адрес бэкенда.

## Что умеет интерфейс

**Шапка и навигация**
- живой тикер зала славы: самая дорогая библиотека и инвентарь, больше всего часов, редчайший трофей, больше всего игр, самая дорогая игра и лента событий. Клик по карточке сразу проверяет этот профиль;
- липкий (sticky) левый сайдбар с четырьмя разделами; на узких экранах он превращается в компактную прокручиваемую панель сверху;
- язык RU / EN / 中文 и валюта ₽ / $ / ¥ — переключаются на лету.

**Обзор**
- время в играх, число игр, портфель целиком (библиотека по текущим ценам + инвентарь), инвентарь;
- AI-куратор: локальный портрет по любимым жанрам, топ-3 играм, возрасту аккаунта, доле непройденного, редким трофеям и стилю игры;
- жанровый компас и средний рейтинг игр критиков с кнопкой «скрытые шедевры»;
- биоритм по часам суток (эвристика — Steam не отдаёт почасовую статистику);
- чистота аккаунта по `GetPlayerBans`: VAC, игровые, торговые и общественные блокировки;
- стоимость библиотеки: сумма, самая дорогая игра, средняя цена игры, реальная цена часа;
- непройденные игры: сколько ни разу не запускали, сколько часов на них уйдёт и сколько они стоят;
- живой статус Steam: «Сейчас играет: …» с кнопкой подключения, онлайн / отошёл / не беспокоить, «был в сети …».

**Библиотека**
- фильтры в один клик: кооператив, «пройти за выходные», «не запускал», «шедевры 85%+», до 15 часов;
- поиск по названию, часы, рейтинг, цена;
- **Smart Pick** на всю ширину: подбор игры на вечер с кнопками «Ещё вариант» и «Запустить». Утилиты и софт (Wallpaper Engine, VTube Studio, Soundpad…) в подбор не попадают.

**Трофеи и история**
- три самых редких достижения в стеклянных рамках;
- «в шаге от платины» — 85–99 % достижений;
- капсула времени с самым первым достижением;
- машина времени: выбор года, доля года в общем времени, средние часы на игру и список игр того года;
- музей игр, снятых с продажи (золотой бейдж).

**Сравнение и друзья**
- баттл 1 на 1 по ссылке друга — двенадцать категорий: часы, игры, портфель, инвентарь, трофеи, процент достижений, средний рейтинг, часы на игру, пройденные на 100 %, уровень Steam, возраст аккаунта и число друзей;
- «идеальный напарник» по общим несыгранным кооперативным играм: прокручиваемый список друзей (до 20, включая закрытые профили без оценки совместимости), порядок меняется перетаскиванием (Drag & Drop).

**Digital Passport**
- коллекционная карточка с кодом карточки и ID профиля;
- анимированный аватар и фон профиля прямо из Steam (видео грузится с CDN, сервер хранит только ссылки);
- скачивание PNG (html2canvas, с резервным отрисовщиком на Canvas, если CDN недоступен);
- ссылка `?profile=…` для шеринга;
- генератор BB-кода для витрины Steam.

## API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/health` | статус, наличие ключа, статистика кэша |
| `GET` | `/api/profile?q=…&lang=ru&cur=RUB` | полный профиль |
| `GET` | `/api/compare?a=…&b=…` | два профиля для баттла |
| `GET` | `/api/hall-of-fame` | рекорды недели и лента событий для тикера |
| `GET` | `/api/avatar-proxy?url=…` | аватар для canvas: только `steamstatic.com` и Steam CDN |
| `GET` | `/api/cache/stats` | размеры кэша |

Параметр `q` принимает всё сразу: `https://steamcommunity.com/id/vanity`, `/profiles/7656119…`, чистый `SteamID64`, никнейм, ссылку на инвентарь или скриншоты.

Ошибки отдают стабильный JSON:

- `403 {"detail":"private"}` — профиль скрыт, фронтенд покажет инструкцию из трёх шагов;
- `404 {"detail":"not_found"}` — никнейм не найден;
- `502 {"detail":"steam_unavailable"}` — Steam молчит, фронтенд покажет экран ошибки с повтором;
- `503 {"detail":"no_api_key"}` — не задан `STEAM_API_KEY`.

## Как это работает внутри

- **Цены** всегда запрашиваются в USD (`cc=us`) и конвертируются на клиенте по курсам `RUB 92.4`, `CNY 7.16`. Курсы — константы в `static/app.js`, их легко заменить.
- **Кэш**: память + `cache.db` (SQLite, WAL). Профиль — 1 час, игры — 6 часов, описания приложений — 7 дней, цены — 24 часа. Это бережёт лимиты Steam и ускоряет повторные проверки.
- **Зал славы**: каждый реально проверенный профиль попадает в недельный пул (до 60 записей) и в ленту событий (до 40). Данные лежат в том же кэше; `/api/hall-of-fame` отдаёт лучших по шести номинациям.
- **Медиа профиля**: анимированный аватар (`GetAnimatedAvatar`) и фон (`GetProfileBackground`) запрашиваются у Steam, с запасным разбором публичной страницы. Сервер хранит только URL — видео и картинки грузит браузер напрямую с CDN.
- **Инвентарь**: CS2, Dota 2, TF2 и Rust через тот же эндпоинт, что и сайт Steam (браузерные заголовки, `Referer`, язык). Закрытый инвентарь помечается как «скрыт», а не как `0,00 ₽`.
- **Биоритм** строится эвристически: Steam не отдаёт почасовую статистику, поэтому активность восстанавливается по профилю (24 столбца) и подписывается как оценка.
- **Аналитика** (стоимость, компас, рейтинг, бэклог, портрет) считается в `static/app.js` по реальному payload. Бэкенд отвечает только за честные исходные данные.
- **Кэшбэк ошибок**: если Steam отдал часть данных, в ответе будет `warnings[]`, а не падение.

## Деплой на бесплатный хостинг

### Render

1. Залей проект в Git-репозиторий.
2. Render → **New → Blueprint** → выбери репозиторий: `render.yaml` уже лежит в корне.
3. Вставь `STEAM_API_KEY` в переменные окружения (Blueprint оставит поле пустым специально).
4. Готово: `https://<name>.onrender.com`.

Free-инстанс засыпает через 15 минут простоя — первый запрос после паузы будет медленнее.

### Koyeb / Amvera / Fly.io

Есть `Dockerfile`, собирается без аргументов:

```bash
docker build -t steam-koshel .
docker run -p 8000:8000 -e STEAM_API_KEY=... steam-koshel
```

На Koyeb: **Create service → GitHub → Dockerfile**, порт `8000`, health check `/api/health`.

### Свой VPS

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

и любой reverse-proxy (Caddy/Nginx) перед ним.

## Приватность и честность

- Пароль Steam не запрашивается никогда. Используются только публичные методы Web API.
- Закрытый профиль не «взламывается» — показывается инструкция, какие две галочки включить.
- Проект не связан с Valve. «Steam» в названии — указание на платформу, а не бренд Valve.
- Все цены и редкости — оценки на момент запроса, а не финансовая или юридическая истина.

## Если что-то не так

**Открыл `index.html` из проводника, а данных нет.** Так и должно быть: из `file://` браузер не ходит в API. Подними бэкенд и открой `http://127.0.0.1:8000`.

**`403 private`.** Steam → Профиль → Изменить профиль → Настройки приватности → «Детали игр»: Открыто.

**Пустые обложки.** Обложки тянутся с CDN Steam; без интернета останутся аккуратные градиентные заглушки с инициалами.

**Не работает скачивание PNG.** Если CDN с html2canvas недоступен, включается резервная отрисовка на Canvas — карточка всё равно сохранится.
